# Vision (VLM Support)

Category: Zdolności Agenta
Local only: yes

## Summary
Włącza obsługę załączników obrazów na czacie. Podczas instalacji pobiera lekki model VLM.

## Agent Instructions
Gdy użytkownik dostarczył obraz, polegaj na zewnętrznym asystencie wizji (Moondream2). Przekazuj wnioski użytkownikowi wprost, ponieważ główny model działa bez natywnej obsługi obrazów.

## Local Runtime Rule
Use only local files, local model reasoning and approved local commands. Do not call cloud APIs unless the user explicitly adds such integration later.
